# Matrix flow — the nine flows of dx/dt = Ax, and which kind of circle each is

*`engine/toolsets/matrix_flow.py` · tutorial: [`examples/51_matrix_flow.py`](../examples/51_matrix_flow.py) · transcript: [`examples/transcripts/51_matrix_flow.txt`](../examples/transcripts/51_matrix_flow.txt) · added in 1.0*

**Kind of factor:** the planar linear flow classified by its eigenvalues, read as the Add:Scale:Sign floor plus one circle.

## Definition

A real 2×2 matrix A drives the flow dx/dt = Ax. Its origin behaves in one of nine ways: centre, stable spiral, unstable spiral, saddle, stable node, unstable node, star, degenerate node, line of fixed points. Every real 2×2 matrix splits exactly as A = a·I + b·J + h1·K1 + h2·K2, where I is SCALE (uniform growth), J is the quarter turn (J² = −I, the circle) and K1, K2 are the boosts (K² = +I, the hyperbola). The sign of h² − b² (h the boost strength, b the turn) says which KIND of circle the flow is: b > h elliptic (round: centre and spirals), b < h hyperbolic (saddle and nodes), b = h parabolic (the shear: the circle at infinity). The shear is the nilpotent ADD generator, N² = 0.

## Why it belongs in the engine

It puts the 'what kind of circle' question on a computable footing. The nine flows are not nine different objects: they are the four generators I, J, K1, K2 in different proportions, and the Cayley–Klein triple (elliptic / parabolic / hyperbolic) that `circle` already carries as a trace test is the same triple seen as a flow. A random integer matrix is almost never a centre: it needs trace 0 and positive determinant.

## The two directions

| direction | what it does | cost |
|---|---|---|
| **`descend`** (free) | a 2×2 matrix -> its class, kind of circle, eigenvalues, the I/J/K split and the invariant that shows the circle | 0 — a single forward pass, no search |
| **`build_up`** (paid, or refused) | an entry bound B -> how many integer matrices with entries in [−B, B] land in each class; cost = matrices tried | reported in `cost`; raises `AscentNotFree` (with `.owed`) when it is asked for something it cannot build from |

**Residual** (what is left when the factor is removed): the Sign: whether the boost or the turn wins, which is the sign of h² − b².

## Guarantee and how it is checked

9 classes each with a representative that classifies as itself. The closed-form exp(tA) (Cayley–Hamilton, no series) agrees with an independent RK4 integration on all nine to 1e-9 (measured 3e-14). The centre conserves x²+y² and has det exp = 1; a spiral's radius is e^{at}; the saddle conserves x·y; the shear is exactly I + tN. The I/J/K split reconstructs A and gives eigenvalues a ± √(h²−b²). The B = 2 scan reaches all nine classes in 625 matrices.

**Limits, stated plainly:** Planar (2×2) only. Class boundaries (det = 0, discriminant = 0, trace = 0) are exact-zero tests under a 1e-12 scaled tolerance, so a matrix within rounding of a boundary is placed on it. The nine are the textbook nine and are exactly the nine panels of the author's source reel (matharium, 2026-10-29); the reel draws one sign for star, saddle and line of fixed points, while here each class covers both signs.

## API

`engine.toolsets.matrix_flow` · registry name `matrix_flow` · line **both** · every call below is made as `lines.<direction>("matrix_flow", ...)` (`from engine import lines`) or directly on the module.

### `descend` — free — `cost = 0`

```python
descend(A)
```

A 2×2 matrix -> class, kind of circle, eigenvalues, the I/J/K split, and the invariant that shows the circle.

| parameter | default | type |
|---|---|---|
| `A` | *required* | — |

**Returns** a dict with keys: `matrix` (list), `class` (str), `kind` (str), `eigenvalues` (tuple), `trace` (float), `det` (float), `split` (dict), `invariant` (str), `free` (bool), `cost` (int).
Example call: `lines.descend("matrix_flow", [[0, -1], [1, 0]])`

### `build_up` — work — reports `cost`, may refuse

```python
build_up(target=3)
```

Scan every integer matrix with entries in [−B, B] (B = target); count the classes. cost = matrices tried.

| parameter | default | type |
|---|---|---|
| `target` | `3` | `Any` |

**Returns** a dict with keys: `bound` (int), `counts` (dict), `cost` (int), `free` (bool).
Example call: `lines.build_up("matrix_flow", 2)`

### `verify()`

`verify() -> {"ok": bool, ...}` — the toolset checks itself. `lines.verify_all()` runs this for every toolset.
