# Jordan–Chevalley — an operator's scaling part and its finite-lifetime part

*`engine/toolsets/jordan_chevalley.py` · tutorial: [`examples/46_jordan_chevalley.py`](../examples/46_jordan_chevalley.py) · transcript: [`examples/transcripts/46_jordan_chevalley.txt`](../examples/transcripts/46_jordan_chevalley.txt) · added in 1.0*

**Kind of factor:** an operator split into two commuting behaviours.

## Definition

Every square matrix A over a perfect field is uniquely **A = S + N** with S·N = N·S, S semisimple (diagonalisable over the algebraic closure — it only *scales*) and N nilpotent (it only shifts along a chain and *dies* after k steps). Both are polynomials in A. Computed here in exact rational arithmetic: the characteristic polynomial by Faddeev–LeVerrier, its squarefree part r = χ/gcd(χ, χ′), then Newton's iteration on matrices S ← S − r(S)·r′(S)⁻¹ starting at S = A, which reaches r(S) = 0 exactly in at most ⌈log₂ n⌉ steps; N = A − S.

## Why it belongs in the engine

It is the operator-level version of the lineage: S is the SCALE-like part, N the part with a finite number of generations. The nilpotency index is how many generations N lives; ranks of the powers of N give the Jordan block sizes (dim ker Nʲ − dim ker Nʲ⁻¹ counts blocks of size ≥ j, size-1 blocks included).

## The two directions

| direction | what it does | cost |
|---|---|---|
| **`descend`** (free) | S, N, nilpotency index, Jordan block sizes of N, the characteristic and squarefree polynomials, the Newton step count, and five re-checked properties | 0 — a single forward pass, no search |
| **`build_up`** (paid, or refused) | build a matrix with a chosen Jordan structure in a chosen basis (the basis is the added constraint — A alone does not return it) | reported in `cost`; raises `AscentNotFree` (with `.owed`) when it is asked for something it cannot build from |

**Residual** (what is left when the factor is removed): N (the nilpotent radical), with its nilpotency index and block sizes.

## Guarantee and how it is checked

Every property is re-checked, not trusted: S + N = A, SN = NS, Nⁿ = 0, r(S) = 0. Checked on seven structures (a single 3-chain, mixed conjugated blocks, two eigenvalues with two chains, diagonalisable, nilpotent, a repeated eigenvalue with a chain and a point, and irrational eigenvalues); S and N also commute with a matrix known to commute with A, as the polynomial-in-A property requires.

**Limits, stated plainly:** Exact arithmetic means Fractions grow; intended for small matrices. Over ℚ only.

## A worked session

Every line below is the literal output of [`examples/46_jordan_chevalley.py`](../examples/46_jordan_chevalley.py), regenerated by `python3 devtools/transcript.py` and checked by the test suite; it starts from its own imports, so it can be read cold.

```text
>>> from engine.toolsets import jordan_chevalley as jc
>>> # Build a matrix with a chosen Jordan structure: a 2-chain at eigenvalue 1, and a lone point at eigenvalue 3.
>>> A = jc.build_up({"blocks": [(1, 2), (3, 1)]})["A"]
>>> [[str(x) for x in row] for row in A]
[['1', '1', '0'], ['0', '1', '0'], ['0', '0', '3']]
>>> # descend() splits A = S + N exactly, in rational arithmetic (no floating point anywhere).
>>> r = jc.descend(A)
>>> [[str(x) for x in row] for row in r["S"]]
[['1', '0', '0'], ['0', '1', '0'], ['0', '0', '3']]
>>> [[str(x) for x in row] for row in r["N"]]
[['0', '1', '0'], ['0', '0', '0'], ['0', '0', '0']]
>>> # N is nilpotent: it lives for `nilpotency_index` generations and then dies.
>>> r["nilpotency_index"], r["jordan_block_sizes_of_N"]
(2, [2, 1])
>>> # Everything was re-checked, not trusted:
>>> r["checks"]
{'S_plus_N_equals_A': True, 'S_N_commute': True, 'N_nilpotent': True, 'S_semisimple_squarefree_minpoly': True}
>>> # A diagonalisable matrix has N = 0; a nilpotent one has S = 0.
>>> d = jc.descend(jc.build_up({"blocks": [(1, 1), (2, 1), (3, 1)]})["A"])
>>> d["is_semisimple"], d["nilpotency_index"]
(True, 1)
```
