### New: ten factor moves (README §§4.19–4.28; one wiki page and one tutorial each)

| toolset | what it factors | kind of factor |
|---|---|---|
| `periodicity` | every period of a string, exactly; Fine–Wilf | periodic structure (a shift symmetry) |
| `lyndon` | a word into its unique non-increasing Lyndon factors | the primes of the word monoid |
| `berlekamp_massey` | a sequence into its shortest recurrence; the period it forces | a generating process |
| `logperiodic` | a spring in u = ln x; the Mellin transform | a non-modular periodic function |
| `permutation` | a re-ordering: cycle type, order, sign, factoradic rank; x ↦ ax + b on ℤ/m | a periodic permutation |
| `rejewski` | the Enigma characteristic, a conjugacy-class invariant | a conjugation-hidden invariant |
| `jordan_chevalley` | A = S + N, exactly | a scaling part and a finite-lifetime part |
| `re_pair` | a sequence's own lineage tree by repeated pairing | a derivation tree |
| `pohlig_hellman` | a discrete log via the lineage of the group order | a hardness read off a factorisation |
| `unicity` | how much ciphertext makes a decomposition unique | evidence needed for well-posedness |

Each has `descend()` (free), `build_up()` (paid, or refuses with `AscentNotFree` naming what it is owed) and `verify()`, and is checked
exhaustively where the space allows.

### New: release infrastructure

- `python3 -m engine` — banner and mode; `--verify` (exit 0 iff everything that ran passed), `--strict` (also fail if anything was
  skipped), `--lines`, `--list`.
- **Core / Extended split, made explicit.** Core needs only numpy; Extended adds `engine.maths`, `engine.tools`,
  `engine.oscilloscope`, which reach four sibling repositories. Both installs were verified from clean clones in fresh virtual
  environments (Core: 27 toolsets ran, 27 passed, 1 skipped; Extended: 28 ran, 28 passed). `engine.EXTENDED` reports the mode.
- `lines.verify_all()` distinguishes *ran and passed*, *ran and failed*, and *did not run*: a skipped Extended toolset is reported as
  skipped, never as passed (`_ok`, `_complete`, `_skipped`).
- `stencil` is now registered in `lines.TOOLSETS` (it was importable and had a `verify()`, but was never run by `verify_all`): 28 toolsets.
- `lines.descend(name, x, *more, **k)` forwards extra positional arguments, so two-argument toolsets (`stencil`, `hyper_linear`) work
  through the dispatcher.
- `from engine import *` works on a Core install (the export list is filtered to what exists); `un_sieve` is exported at the package
  root; `engine.__version__` added.
- 41 tutorials in `examples/`, each with a REPL transcript **generated by running it** (`devtools/transcript.py`); a 152-test
  suite (Core: 150 passed, 2 skipped); `devtools/build_docs.py` regenerates the toolset table, the ten move pages, the Tools Reference
  and the tutorial index from the live registry.
- `requirements.txt`, `requirements-dev.txt`, `pyproject.toml`, `INSTALL.md`, `LICENSE` (GPL v3), `AUTHORS`, `CITATION.cff`,
  `CONTRIBUTING.md`, `CODE_OF_CONDUCT.md`, `SECURITY.md`, issue and pull-request templates, and a CI workflow *definition* (`.github/ci-workflow.yml` — it is not yet enabled: pushing into
  `.github/workflows/` needs a token with the `workflow` scope; see `.github/README.md`).
- Documentation: a white-paper README (abstract, install, quickstart, repository map, provenance labels, tutorial index, known
  limitations); new wiki pages `Tools-Reference`, `Glossary`, `References`, `Reproducibility`; the ADD:SCALE:SIGN page gained the
  account of what SIGN does and does not decide about the Noether-current direction.

### Known limitations

See the README's *Known limitations*: the package imports as `engine`; the Extended layer edits `sys.path`; run-tested on Python 3.12 /
Linux only; several tools are teaching-scale; `logperiodic` is a numerical fit with uncharacterised noise robustness.
