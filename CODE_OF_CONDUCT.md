# Code of Conduct

This project is a place to argue about mathematics and engineering, and the arguments should be about the work.

**Expected:** be specific and be kind; assume good faith and ask before assuming otherwise; criticise code, claims and evidence, not
people; credit others' work; say plainly when you are unsure or wrong; welcome newcomers and questions.

**Not acceptable:** harassment, insults, personal attacks, discrimination, doxxing, sustained disruption, or publishing someone's
private information. Disagreement about a claim is welcome; contempt for a person is not.

**Scope:** this applies in the repository — issues, pull requests, discussions, and any space where someone is representing the
project.

**Enforcement:** report problems to the.wandering.god@gmail.com. Reports are read by the maintainer and handled privately. The
maintainer may edit or remove comments, close threads, and block accounts that break these expectations.

This statement is deliberately short. It is in the spirit of the Contributor Covenant (https://www.contributor-covenant.org).
